# 구현 과정과 설계 선택

현재 Apps Script 소스를 기준으로, 구현한 기능과 그 이유를 정리한 문서입니다.

## 1. 핵심 기능에 집중

초기 범위는 재료 입력, 레시피 추천, 조리 방법 확인으로 정했습니다. 화면은 홈·검색 결과·상세 화면으로 구성하고, 페이지 이동 없이 전환합니다. 사진 갤러리는 안내 문구만 있으며 기능은 구현하지 않았습니다.

별도 서버를 구축하는 부담을 줄이기 위해 Apps Script를 서버로, Google Sheets를 데이터 저장소로 사용했습니다. 화면과 서버는 Apps Script 전용 `google.script.run`으로 연결합니다.

## 2. 기존 데이터와 AI를 결합

검색할 때마다 AI로 새 레시피를 만드는 대신, 이전 결과와 기존 레시피를 먼저 사용하도록 구성했습니다.

```text
재료 입력
  → 공백·중복 정리 및 기본 조미료 제외
  → 임시 캐시에 결과가 있으면 반환
  → 잠금 획득 후 임시 캐시 재확인
  → 시트에 저장한 이전 검색 결과 조회
  → 기존 레시피 검색으로 추천 보충
  → 최대 3개에서 부족한 개수만 Gemini로 생성
  → 생성 레시피와 검색 결과 저장
  → 검색 횟수 갱신 및 임시 캐시 저장
  → 결과 반환
```

임시 캐시 유지 시간은 코드에서 6시간으로 설정했습니다. 시트에도 검색 결과를 저장해 임시 캐시가 없어져도 재사용할 수 있도록 했습니다. 생성한 레시피는 `setValues()`로 묶어서 저장합니다.

관련 코드: `searchRecipes()`, `findMatchingRecipes_()`, `generateRecipesWithGemini_()`, `appendGeneratedRecipes_()`.

## 3. 중복 생성과 저장 줄이기

동시에 같은 검색이 들어오면 같은 레시피를 여러 번 생성할 수 있습니다. 이를 줄이기 위해 `LockService`로 작업을 순서대로 처리하고, 잠금을 얻은 다음 캐시를 다시 확인합니다. 잠금을 기다리는 동안 앞선 요청이 만든 결과가 있으면 재사용합니다.

현재 잠금은 스크립트 전체에 적용됩니다. 서로 다른 검색도 대기할 수 있어, 많은 사용자가 동시에 이용할 때는 처리량 개선이 필요합니다.

## 4. 연결 설정과 비밀값 분리

웹앱 실행에서는 활성 문서에 의존하지 않도록 `SPREADSHEET_ID`를 읽어 `SpreadsheetApp.openById()`로 시트를 엽니다. API 키도 `PropertiesService`에서 읽으며, 화면으로 전달하는 레시피 데이터와 분리합니다.

`verifySetup()`으로 시트 존재 여부와 API 키 설정을 확인할 수 있습니다. 실제 API 호출 성공 여부는 검색을 통해 별도로 확인해야 합니다.

## 5. 모바일 화면과 사용자 피드백 보완

- 검색 중에는 진행 상태를 보여주고 검색 버튼을 비활성화합니다.
- 긴 요리 제목과 재료 목록은 작은 화면에서도 읽을 수 있도록 줄바꿈을 적용했습니다.
- AI 요청 제한이나 일시적인 혼잡은 사용자가 이해하기 쉬운 안내로 표시합니다.
- Apps Script의 중첩 프레임에서 모바일 화면 폭이 크게 인식되는 상황을 보완하도록 첫 진입 시 화면 배율을 조정합니다. 키보드 열림·닫힘에 맞춰 반복 조정하지 않습니다.
- 레시피 내용을 HTML에 넣을 때 특수문자를 변환하는 `esc()` 함수를 사용합니다.

모바일 화면 확인과 실제 휴대폰에서의 확인은 구분해야 합니다. 이 문서는 현재 구현을 설명하며, 모든 기기에서의 검증이나 성능 측정 결과를 의미하지 않습니다.

## 6. 현재 범위와 후속 작업

AI 호출 감소를 위한 구조는 구현했지만, 비용 절감률이나 동시 접속 처리량을 측정한 수치는 없습니다. AI 추천의 정확도와 알레르기 정보도 별도 검토가 필요합니다.

Cloudflare 이전 준비 코드는 [`codex/cloudflare-migration` 브랜치](https://github.com/cupid75/bangguseok-chef/tree/codex/cloudflare-migration)에 보존했습니다. 해당 시점에는 상태 확인용 Worker API와 D1 연결 설정이 있으며, 레시피 검색 이전은 완료되지 않았습니다. 기본 브랜치에는 현재 Apps Script 버전의 소스와 설명 문서만 유지합니다.
