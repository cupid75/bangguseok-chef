# 실행 및 배포 방법

이 문서는 저장소의 Google Apps Script 버전을 자신의 Google 계정에서 실행하는 방법입니다. HTML 파일을 컴퓨터에서 직접 열면 `google.script.run`을 사용할 수 없으므로 검색이 동작하지 않습니다.

## 1. 준비할 것

- Google 계정과 Google Sheets 문서
- Google Apps Script 프로젝트
- 자신의 Gemini API 키와 해당 계정에서 사용할 수 있는 모델

API 키는 채팅이나 GitHub에 올리지 않습니다. API 이용 한도와 비용은 본인의 계정 설정을 확인합니다.

## 2. 소스 등록

Apps Script 프로젝트에 다음 두 파일을 등록합니다.

| Apps Script 파일 | 복사할 저장소 파일 |
| --- | --- |
| `Code.gs` | `legacy-apps-script/Code.gs` |
| `Index.html` | `legacy-apps-script/Index.html` |

HTML 파일 이름은 `Index`로 지정합니다. 서버의 `doGet()` 함수가 이 이름으로 화면을 불러옵니다.

## 3. Google Sheets 구성

하나의 스프레드시트에 `레시피`, `검색캐시`, `기본조미료` 시트를 만듭니다. 아래 각 줄을 복사해 해당 시트의 A1 셀에 붙여 넣으면 탭으로 구분된 열이 만들어집니다.

### 레시피

코드는 아래 이름으로 열을 찾으며, 새 레시피는 아래 순서로 저장합니다. 열 이름과 순서를 유지합니다.

```text
레시피ID	요리제목	구성재료	정규화재료	조리시간(분)	인분	필수도구	대체재료	알레르기주의	만드는방법	생성출처	사용여부	등록일	수정일	검색횟수
```

처음에는 헤더만 있어도 됩니다. 검색 결과가 부족하면 Gemini로 생성해 저장합니다. 직접 데이터를 넣는 경우 ID는 `R0001`과 같은 형태로, 재료 목록은 쉼표로 구분합니다. `사용여부`가 `숨김`이면 추천에서 제외됩니다.

### 검색캐시

이 시트는 열 위치를 기준으로 읽고 씁니다. 다음 6개 열을 순서대로 만듭니다. 첫 줄은 설명용 헤더이며, 검색 결과는 앱이 기록합니다.

```text
검색키	입력재료	레시피ID목록	등록일	수정일	검색횟수
```

### 기본조미료

이 시트도 열 위치를 기준으로 읽습니다. 첫 줄은 아래 헤더를 넣고, 두 번째 줄부터 데이터를 입력합니다.

```text
조미료명	별칭	사용여부
소금	천일염,꽃소금	Y
식용유	카놀라유,콩기름	Y
```

`Y`인 항목만 기본 조미료로 취급합니다. 별칭은 쉼표로 구분합니다. 이 표는 운영 데이터가 아닌 구성 예시입니다.

## 4. 스크립트 속성 설정

Apps Script 프로젝트 설정의 **스크립트 속성**에 다음 값을 등록합니다.

| 속성 이름 | 값 |
| --- | --- |
| `SPREADSHEET_ID` | 사용할 Google Sheets 주소의 `/d/`와 `/edit` 사이 문자열 |
| `GEMINI_API_KEY` | 본인이 발급한 Gemini API 키 |

`Code.gs` 상단의 `CONFIG.GEMINI_MODEL`도 본인의 계정에서 이용 가능한 모델 이름인지 확인합니다. 저장소에 기록된 모델의 현재 제공 여부는 별도 확인이 필요합니다.

## 5. 연결 확인

Apps Script 편집기에서 `verifySetup()`을 실행하고, 본인의 시트 접근과 외부 API 요청에 필요한 Google 권한을 승인합니다. 실행 로그에서 시트 연결과 API 키 설정 여부를 확인합니다. 이 함수는 실제 Gemini 응답까지 검사하지는 않습니다.

별도로 OAuth 범위를 직접 지정한 프로젝트라면 다음 두 범위가 필요합니다. `spreadsheets.currentonly`만으로는 `openById()`로 문서를 열 수 없습니다.

```text
https://www.googleapis.com/auth/spreadsheets
https://www.googleapis.com/auth/script.external_request
```

## 6. 웹앱 배포 및 확인

1. Apps Script에서 새 배포를 만들고 유형을 **웹 앱**으로 선택합니다.
2. 실행 주체는 프로젝트 소유자로 설정합니다.
3. 외부 방문자에게 공개할 경우 접근 대상을 **모든 사용자**로 설정합니다.
4. 발급된 `/exec` 주소로 접속합니다.
5. `계란, 양파` 등을 입력해 검색 결과와 상세 조리 방법이 표시되는지 확인합니다.
6. 로그아웃한 브라우저에서도 사이트가 열리는지 확인합니다. 모바일에서는 첫 화면과 키보드를 열었을 때의 화면도 확인합니다.

공개 웹앱의 검색은 소유자의 Google 및 Gemini 사용량을 사용합니다. 배포 후 코드를 수정했다면 기존 배포가 새 버전을 사용하도록 갱신합니다. GitHub에 소스를 푸시하는 것만으로 Apps Script 배포가 바뀌지는 않습니다.
